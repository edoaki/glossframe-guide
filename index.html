対応アプリ: 0.1.0 / A・Bセットアップ機能は実装・検証中。公開リポジトリに npm run setup がない場合は、既存の導入手順を利用してください。

準備するもの

データは、
あなたのアカウントへ。

Cloudflareアカウントとインターネット接続が必要です。PCで導入する場合はNode.js 22以上とGitを用意してください。公開リポジトリのクローンにGitHubログインは不要です。

OCRは端末内、翻訳はWorkers AI、単語帳はD1、保存する画像はKVを使います。Cloudflareの無料枠には上限があります。課金設定・利用量はCloudflare公式画面で確認してください。

対象OS: macOS / Linux / Windows。macOSでローカル検証済み。Linux・Windowsのクリーン環境、本番デプロイ、スマホ実機は確認待ちです。

A · WITH YOUR COMPUTER

最初のコマンドのあとは、ブラウザで。

進捗のチェックはこのブラウザに保存されます。パスワード・認証情報はこの説明サイトに入力しません。

01

PCで準備して、セットアップを開く

Node.jsとGitを用意し、ターミナルで実行します。セットアップ機能が含まれるソースを使用してください。

git clone https://github.com/edoaki/glossframe.git
cd glossframe
npm ci
npm run setup

このPCだけで開けるセットアップ画面が起動します。自動で開かない場合は、ターミナルに表示されたURLをブラウザで開いてください。URLは他人と共有しないでください。

02

Cloudflareに接続する

「接続状態を確認」を押します。未ログインなら「Cloudflareにログイン」を押し、Cloudflareの公式画面でログイン・権限許可を行います。終わったらローカル画面に戻り、対象アカウントを確認してください。

03

パスワードを決めて、デプロイ

新規導入では「新規環境」を選び、アプリ専用のパスワードを2回入力します。8〜200文字で、CloudflareやGitHubとは別のパスワードにしてください。

アカウントと利用枠を確認して「デプロイ / 再試行」を押します。D1・KVの準備、ビルド、DB更新、所有者登録、公開、起動確認の順に進みます。数分かかる場合があります。

既存の wrangler.jsonc がある場合は「既存環境」を選びます。登録済みの所有者と学習データを保持して更新します。更新前にはCloudflareでDBのバックアップを確認してください。

04

スマホへ引き継ぐ

完了画面のHTTPS URLを開いて、設定したパスワードでログインしてください。スマホはQRコードから同じURLを開けます。

OCRの初回準備後、画像の読み取り、AI翻訳、単語帳への保存、ログアウトと再ログインを確かめましょう。確認が終わったら、PCのセットアップ画面で「終了」を押してください。

WHEN SOMETHING STOPS

途中で止まっても、同じ場所から。

ログインを中断した・接続できない

通信とCloudflareのログイン状態を確認し、ローカル画面からログインをやり直してください。対象アカウントにD1・KV・Workers・Workers AIを利用する権限が必要です。

リソース作成・ビルド・デプロイで失敗した

失敗した段階を画面で確認し、接続・利用上限・権限を確認して「デプロイ / 再試行」を押します。作成済みリソースはPCの記録から再利用します。画面を閉じた場合は、同じフォルダで npm run setup を実行してください。

.local-work/setup/state.json と wrangler.jsonc は削除しないでください。パスワードは保存しないので、再試行時に同じパスワードを入力します。登録済みなら再登録しません。

別タブで説明を読みたい・分割ビューを使いたい

PCのChromeではリンクを右クリックし「リンクを分割ビューで開く」を選べます。項目がない場合は別タブで開いてください。このサイトから分割ビューを自動起動することはありません。Chrome公式の操作説明

パスワードを忘れた

Cloudflare管理権限のあるPCで、アプリのフォルダから npm run password:reset を実行します。学習データは保持し、既存セッションを失効させます。

テストの準備はできています。 下のボタンから進み、使いたいメールアドレスをCloudflare公式画面で入力してください。このページではメールアドレスを収集しません。

自分用のGlossFrameを作る ↗
B01

公式画面へ進む

上のボタンを押し、Cloudflareへログインします。別のアカウントを使う場合は、表示されたアカウントを確認して切り替えてください。新規作成時はメール認証も完了します。

B02

GitHubを連携する

公式画面でGitHubとの連携を許可し、コピーの保存先を選びます。名前が重複したら別の名前を選びます。アプリと保存データは選択した自分のアカウントに作成されます。

B03

アプリのパスワードを決める

Cloudflareの INITIAL_OWNER_PASSWORD に8〜200文字のアプリ専用パスワードを入力し、手元のパスワード管理アプリへ保存します。共通の初期パスワードはありません。この説明サイトには入力しません。

B04

デプロイを待つ

D1・KV・Workers AIを確認して開始します。ビルドとデプロイの既定値は npm run build と npm run deploy です。OCRモデルの取得やビルドに数分かかる場合があります。

B05

完成したURLを開く

発行されたHTTPS URLを開き、決めたパスワードでログインします。OCR準備後に画像の翻訳、単語保存、再ログインを確認してください。

進捗はこのブラウザに保存されます。外部画面の操作状況は読み取らないため、説明へ戻って手動でチェックしてください。保存するのはチェック状態だけです。

スマホからパスワードを復旧する

CloudflareのWorker設定でSecret OWNER_RECOVERY_TOKEN に新しい32〜200文字のランダムなキーを設定してDeployします。アプリの「パスワードを忘れた場合」に同じキーと新しいパスワードを入力します。学習データを保持し、全端末のセッションを失効させます。完了後はCloudflareのキーを削除してください。キーは一度しか使えません。

更新・バックアップ・削除

更新前にアプリからバックアップJSONを保存します。画像は別途保管してください。コピーは自動更新されません。GitHub Actionsの「Prepare app update」で更新ブランチを作り、内容とCheckを確認してMergeすると、Cloudflareで再ビルドされます。

検証中の main はB未対応です。今回の検証版では mobile-setup-preview が更新先の既定値です。設定やワークフローの変更を含む更新は別途移行案内を確認します。

WorkerのロールバックはD1を戻しません。削除するときは必要なデータを保存してから、Workerと専用のD1・KVを個別に削除します。共有リソースは削除しません。

Workers AI・D1・KV・ビルドには無料枠の上限があります。上限到達や通信障害時は処理が失敗する場合があります。料金と利用枠を確認する ↗

公式画面のスクリーンショットは、Bの実操作を確認してから追加します。アカウント情報やパスワードは掲載しません。
