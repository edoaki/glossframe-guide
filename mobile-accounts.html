B · ACCOUNT SETUP

アカウントの有無に合わせて、
ひとつずつ進める。

CloudflareとGitHubは別のサービスです。Googleアカウントを持っていても、両方の登録が済んでいるとは限りません。メールアドレスやパスワードは各サービスの公式画面だけに入力します。

2026-10-23のChrome実画面を記録中です。「確認済み」と「確認待ち」を分けて掲載しています。スマホ実機の確認はこれから行います。

CloudflareアカウントがないCloudflareアカウントがある

最初に押すボタン

自分用のGlossFrameを作る ↗

Cloudflareの公式画面が別タブで開きます。画面のURLが dash.cloudflare.com であることを確認します。この説明は元のタブに残るので、行き来しながら進められます。

すぐに「Set up your application」が表示された場合は、すでにログイン済みです。GitHubを接続するへ進みます。

CLOUDFLARE · NEW ACCOUNT

Cloudflareアカウントがない場合

01

「Sign up」を押す

「Sign in to Cloudflare」が表示されたら、画面上部または「Don't have an account?」の横にある Sign up を押します。

「Continue as … using Google」のように保存済みのアカウントが表示されても、「Sign up」リンクから新規登録画面へ進めます。別のアカウントを使いたい場合は、表示されたメールアドレスをそのまま選ばないでください。

確認済み：通常のログイン画面と、保存済みプロフィールがある画面の両方にSign upがあります。

02

「Continue with Google」を押す

「Build, protect, and connect with Cloudflare」という見出しの登録画面が開きます。上部の Continue with Google を押して、Googleを使う登録へ進みます。

この方法では、下のEmailとPassword欄に入力して「Sign up」を押す経路とは分かれます。続行はCloudflareの規約への同意を伴うため、表示された規約を確認してください。

確認済み：Sign upを押したあとの画面とGoogleボタン。Google選択後の新規登録完了画面は確認待ちです。

03

Googleの選択・認証後の画面

今回の検証ではGoogleでの操作後にCloudflareのホーム（「Pick up where you left off.」）へ移りました。ホームに着いた場合は、元の説明タブへ戻り「自分用のGlossFrameを作る」をもう一度押してください。「Set up your application」へ戻れます。
今回のメールアドレスには検証開始時点ですでにCloudflareアカウントがありました。新規アカウントだけに出る追加確認の有無は未検証です。

CLOUDFLARE · EXISTING ACCOUNT

Cloudflareアカウントがある場合

すでにログインしている場合

ガイドの「自分用のGlossFrameを作る」から直接「Create an app」内の Set up your application に進みます。左上の Switch Account で利用するアカウントを確認します。正しければGitHubの接続へ進みます。

この経路は実画面で確認済みです。

ログアウトしている場合

Googleで登録した人は「Sign in to Cloudflare」で Continue with Google を選びます。保存済みプロフィールが表示された場合は、メールアドレスが正しいことを確認し、Continue as … using Google を選びます。

別のプロフィールが表示されていたら Sign in with another profile を押します。Google、Apple、GitHub、SSOと、Email／Passwordによるログインが表示されます。登録時に使った方法を選んでください。

確認済み：ログアウト後の選択肢と、Googleでの操作後にホームから導入ボタンへ戻る経路。ホームへ移った場合は、説明タブに戻り「自分用のGlossFrameを作る」をもう一度押します。

GITHUB · CONNECT

GitHubアカウントの有無で分かれる

「Set up your application」の Git account にある New GitHub connection が入口です。

GitHubアカウントがないGitHubアカウントがある

GitHubアカウントがない場合

  1. Cloudflareの New GitHub connection を押します。
  2. 「Sign in to GitHub to continue to Cloudflare Workers and Pages」が開きます。下部の「New to GitHub?」の横にある Create an account を押します。
  3. 短い端末チェック画面を挟む場合があります。自動で進むまで待ちます。
  4. 「Sign up for GitHub」で Continue with Google を押します。Googleを使う場合、下のEmail・Password・Usernameを使う別の登録フォームにはまだ入力しません。
  5. Googleの「アカウントを選択してください」で、使いたいアカウントを選びます。違うアカウントしか出ない場合は 別のアカウントを使用 を選びます。
  6. 「GitHub にログイン」で、GitHubに渡す名前・プロフィール写真・メールアドレスを確認し、次へ を押します。

ここまでの画面と、その後に表示される「Install & Authorize Cloudflare Workers and Pages」を確認しました。途中で登録情報の入力や本人確認が表示された場合は、画面の案内に従います。入力項目の詳細は継続確認中です。

GitHubアカウントがある場合

Cloudflareの New GitHub connection を押した先のログイン画面には、次の選択肢があります。登録時に使った方法を選びます。

  • Googleで登録：Continue with Google
  • メールアドレス／ユーザー名とパスワードで登録：Username or email address と Password を入力し、Sign in
  • Appleで登録：Continue with Apple
  • パスキーを設定済み：Sign in with a passkey

選択肢の表示は確認済みです。登録を完了してからログアウトし、登録済みユーザーとして最後まで進む確認はこれから行います。

CloudflareとGitHubの連携を許可する

「Install & Authorize」が表示されたら

  1. 見出しが Install & Authorize Cloudflare Workers and Pages であることを確認します。
  2. 「on your personal account」の後に、自分のGitHubユーザー名が表示されていることを確認します。
  3. リポジトリの許可範囲を確認します。All repositories は現在と今後のすべてのリポジトリが対象です。Only select repositories は既存のリポジトリを選んで対象を限定します。これから初めてリポジトリを作るアカウントでは、選べる既存リポジトリがない場合があります。
  4. 下の権限一覧を確認します。この画面には、メタデータの読み取りと、管理・チェック・コード・デプロイ・Pull Requestの読み書きが表示されます。
  5. この範囲を許可する場合は、緑の Install & Authorize を押します。許可しない場合は Cancel で戻ります。
  6. Cloudflareに戻ります。「Select a repository」で「No Git repositories found on this account」と表示された場合は、説明タブへ戻り、自分用のGlossFrameを作る をもう一度押します。ここで手動でリポジトリを作る必要はありません。

連携許可画面と、許可後にCloudflareへ戻るところまで実画面で確認済みです。アカウントを持っている場合でも、Cloudflareを初めて連携するときはこの許可が必要になる場合があります。

GitHubを選び、パスワードを決めてデプロイする

  1. 「Set up your application」の Git account → Select... を押します。
  2. 「Connected accounts」に表示された自分のGitHubユーザー名を選びます。選択欄がそのユーザー名に変わったことを確認します。
  3. INITIAL_OWNER_PASSWORD に、GlossFrameへの初回ログインで使う専用パスワードを入力します。あとで必要なので、ご自身のパスワード管理方法で保管してください。
  4. 下の設定を確認し、画面下の Deploy を押します。

アカウント選択まで実画面で確認済みです。パスワード入力・Deploy後の画面は継続確認中です。次の項目は初期値のままで進めます。

  • Project name：glossframe
  • Select KV namespace／Select D1 database：+ Create new
  • Name your KV namespace／Name your D1 Database：glossframe
  • Database location hint：Automatic
  • INITIAL_OWNER_PASSWORD：アプリ専用パスワードの入力欄
  • Build command：npm run build
  • Deploy command：npm run deploy
  • Preview command：npx wrangler preview
  • 画面下の実行ボタン：Deploy

「最初から」の確認方法

アカウントや保存データを消す必要はありません。Cloudflare homeへ戻り、右上の User menu → Log out でログアウトし、ガイドの導入ボタンを再度押します。これはログイン状態をリセットする操作で、アカウント削除ではありません。

実画面確認日：2026-10-23。個人のメールアドレス・アカウントID・認証情報は掲載しません。
