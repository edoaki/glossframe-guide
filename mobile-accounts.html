アカウントの有無に合わせて、
ひとつずつ進める。

CloudflareとGitHubは別のサービスです。Googleアカウントを持っていても、両方の登録が済んでいるとは限りません。メールアドレスやパスワードは各サービスの公式画面だけに入力します。

2026-10-23のChrome実画面を記録中です。「確認済み」と「確認待ち」を分けて掲載しています。スマホ実機の確認はこれから行います。

CloudflareアカウントがないCloudflareアカウントがある

最初に押すボタン

自分用のGlossFrameを作る ↗

Cloudflareの公式画面が別タブで開きます。画面のURLが dash.cloudflare.com であることを確認します。この説明は元のタブに残るので、行き来しながら進められます。

すぐに「Set up your application」が表示された場合は、すでにログイン済みです。GitHubを接続するへ進みます。

CLOUDFLARE · NEW ACCOUNT

Cloudflareアカウントがない場合

01

「Sign up」を押す

「Sign in to Cloudflare」が表示されたら、画面上部または「Don't have an account?」の横にある Sign up を押します。

「Continue as … using Google」のように保存済みのアカウントが表示されても、「Sign up」リンクから新規登録画面へ進めます。別のアカウントを使いたい場合は、表示されたメールアドレスをそのまま選ばないでください。

確認済み：通常のログイン画面と、保存済みプロフィールがある画面の両方にSign upがあります。

02

「Continue with Google」を押す

「Build, protect, and connect with Cloudflare」という見出しの登録画面が開きます。上部の Continue with Google を押して、Googleを使う登録へ進みます。

この方法では、下のEmailとPassword欄に入力して「Sign up」を押す経路とは分かれます。続行はCloudflareの規約への同意を伴うため、表示された規約を確認してください。

確認済み：Sign upを押したあとの画面とGoogleボタン。Google選択後の新規登録完了画面は確認待ちです。

03

Googleの選択・認証後の画面

実操作を確認して追記します。追加の同意、メール認証、初回の案内が出るかを記録中です。確認できていないボタン名はここでは断定しません。

CLOUDFLARE · EXISTING ACCOUNT

Cloudflareアカウントがある場合

すでにログインしている場合

ガイドの「自分用のGlossFrameを作る」から直接「Create an app」内の Set up your application に進みます。左上の Switch Account で利用するアカウントを確認します。正しければGitHubの接続へ進みます。

この経路は実画面で確認済みです。

ログアウトしている場合

Googleで登録した人は「Sign in to Cloudflare」で Continue with Google を選びます。保存済みプロフィールが表示された場合は、メールアドレスが正しいことを確認し、Continue as … using Google を選びます。

別のプロフィールが表示されていたら Sign in with another profile を押します。Google、Apple、GitHub、SSOと、Email／Passwordによるログインが表示されます。登録時に使った方法を選んでください。

確認済み：ログアウト後の選択肢。ログイン後に導入画面へ戻る経路は確認中です。ホームへ移った場合は、説明タブに戻り「自分用のGlossFrameを作る」をもう一度押します。

デプロイ設定画面で確認できた項目

次の既定値が公式画面に表示されることを確認しました。GitHub接続後に入力・選択がどう変わるかは継続して確認します。

  • Project name：glossframe
  • Select KV namespace／Select D1 database：+ Create new
  • Name your KV namespace／Name your D1 Database：glossframe
  • Database location hint：Automatic
  • INITIAL_OWNER_PASSWORD：アプリ専用パスワードの入力欄
  • Build command：npm run build
  • Deploy command：npm run deploy
  • Preview command：npx wrangler preview
  • 画面下の実行ボタン：Deploy

「最初から」の確認方法

アカウントや保存データを消す必要はありません。Cloudflare homeへ戻り、右上の User menu → Log out でログアウトし、ガイドの導入ボタンを再度押します。これはログイン状態をリセットする操作で、アカウント削除ではありません。
